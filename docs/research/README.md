# 研究档案 · Research Archive

Amor Mundi（汉娜·阿伦特）项目的研究档案。网站是快照，档案是活水：这里的每一份笔记，都是网站内容长出来的依据。

## 档案格式

每份笔记一个文件，命名 `YYYY-MM-DD-<主题>.md`，必须包含以下几节：

1. **问题** — 这份笔记要回答什么（对应网站上的哪个缺口）。
2. **查过的来源** — 逐个列出实际打开过的来源（书名、文章、网页链接），并写明读到的是什么：全文 / 摘要 / 目录 / 二手转述。
3. **结论** — 逐条写，每条标明依据是哪个来源、具体到哪一页或哪一段。
4. **核实状态** — 每条结论只能是以下三种之一：`已核实`（有确切出处）、`部分核实`（出处不完整）、`待核实`（没找到，或来源互相矛盾）。
5. **对网站意味着什么** — 具体提议：哪条摘录挪库、新增什么内容、哪条记进《推翻记录》。只提议，不直接改网站文件。

## 铁律

- **不编造。** 拿不准的一律标「待核实」，不要用漂亮话填格子。
- 引文必须有书名 + 章节（或信件日期）+ 页码；翻译注明译者或「本项目自译」。
- **只写实际看到的东西**：读到的是摘要就写摘要，读到的是二手转述就写二手转述，不许把摘要说成读过全文。
- 权威来源优先：Stanford Encyclopedia of Philosophy、Britannica、Bard Hannah Arendt Center、Goethe-Institut 书目、HannahArendt.net、出版社页面、Google Books 预览。网络语录合集（Wikiquote 之类）只能当线索，不能当出处。
- 每份笔记写明查了哪些来源、每个结论的依据。没有依据的结论不进档案。

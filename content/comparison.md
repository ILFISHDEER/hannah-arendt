# 她与其他哲学家的不同

总纲一句话：别的哲学家多在问“人是什么、真理是什么”，她在问“人在一起时发生了什么、没有他人时人会变成什么”。

| 对照 | 她继承了什么 | 她不要什么 / 她改成什么 |
|---|---|---|
| 康德 Kant | 判断力、公共理性 | 不要普遍法则；判断不是套公式，是在没有标准时还能看、还能说“这是不对的” |
| 黑格尔 Hegel | 历史意识 | 反历史必然性；历史没有方向，人的行动才是新的开始 |
| 海德格尔 Heidegger | 存在、世界、语言 | 把“独处沉思”拉回“与他人共在的世界”；他讲本真性，她讲复数性 |
| 雅斯贝尔斯 Jaspers | 思考即对话、沟通 | Jaspers 更重内在超越，她更重公共显现 |
| 马克思 Marx | 对现代性的诊断 | 反劳动中心论：劳动不是人的最高活动，行动才是 |
| 柏拉图 / 传统哲学 | 概念的严谨 | 传统哲学重沉思、轻行动；她反过来：行动高于沉思，政治不是统治，是众人一起显现 |
| 存在主义（萨特等） | 自由、选择 | 不要“孤独的自由”；自由不是一个人做决定，是和他人一起开始、一起承担后果 |
| 自由主义 / 保守主义 | 对自由的关切 | 既不要“社会问题化一切”，也不要“回到传统”；她要的是公共领域本身 |

她 1964 年对 Gaus 说：“我不是哲学家，我是政治理论家。”不是谦虚，是划界：
哲学关心“人”（单数、抽象），她关心“人们”（复数、具体）。
她不是体系建造者，座右铭是“没有扶手的思考 Denken ohne Geländer”。
